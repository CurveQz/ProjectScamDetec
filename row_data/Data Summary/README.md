# Thai SMS Dataset V2

ชุดข้อมูลข้อความ SMS ภาษาไทย สำหรับงานจำแนกประเภทข้อความ (Text Classification) แยกระหว่างข้อความปกติ (positive) และข้อความหลอกลวง/สแปม (negative)

---

## ไฟล์ในชุดข้อมูล

| ไฟล์ | คำอธิบาย | จำนวนแถว |
|------|-----------|-----------|
| `positive_all_V2.csv` | ข้อความ SMS ปกติ | 770 |
| `negative_all_V2.csv` | ข้อความ SMS หลอกลวง/สแปม | 491 |
| `all_V2.csv` | รวมทั้งสองชุดและสุ่มลำดับ | 1,261 |

---

## โครงสร้างข้อมูล (Columns)

| คอลัมน์ | คำอธิบาย |
|---------|-----------|
| `id` | หมายเลขลำดับ |
| `sentence_raw` | ข้อความต้นฉบับ (ไม่แก้ไข) |
| `sentence` | ข้อความที่ผ่านการ normalize (URL → `<URL>`, จำนวนเงิน → `<AMOUNT>`) |
| `group` | ประเภทหลัก: `positive` หรือ `negative` |
| `sub_group` | ประเภทย่อย (ดูด้านล่าง) |
| `source` | แหล่งที่มาของข้อมูล |

---

## ประเภทย่อย (sub_group)

### Positive (770 แถว)

| sub_group | ความหมาย | จำนวน |
|-----------|-----------|-------|
| `promotion` | SMS โปรโมชันสินค้า/บริการ | 495 |
| `carrier_vas` | SMS บริการเสริมจากผู้ให้บริการเครือข่าย | 103 |
| `otp` | SMS รหัส OTP / ยืนยันตัวตน | 62 |
| `service_notice` | SMS แจ้งเตือนบริการ | 57 |
| `payment_alert` | SMS แจ้งชำระเงิน / รายการทางการเงิน | 35 |
| `transfer` | SMS แจ้งโอนเงิน | 11 |
| `gov_announcement` | SMS ประกาศจากหน่วยงานรัฐ | 4 |
| `call_system` | SMS จากระบบโทรศัพท์/Call center | 3 |

### Negative (491 แถว)

| sub_group | ความหมาย | จำนวน |
|-----------|-----------|-------|
| `invite` | SMS ชักชวนพนัน / รางวัลปลอม / งานออนไลน์หลอกลวง | 301 |
| `phishing_link` | SMS แนบลิงก์ฟิชชิ่ง / ปลอมเป็นธนาคาร-หน่วยงาน | 157 |
| `threat` | SMS ข่มขู่ / แจ้งเตือนเท็จ เพื่อกดดันให้ดำเนินการ | 33 |
