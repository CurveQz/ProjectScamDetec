# แหล่งอ้างอิงและที่มาของข้อมูล

*** ข้อมูลเหล่านี้สร้างโดยใช้ AI โดยอ้างอิงโครงสร้างจากแหล่งข้อมูล ดังนี้

## Positive

ธนาคารกสิกรไทย – SMS ขยันบอก

ธนาคารกรุงเทพ – SMS Account Alert

ธนาคารแห่งประเทศไทย – OTP

สมาคมธนาคารไทย – แนวทางคุ้มครองข้อมูลส่วนบุคคล

งานวิจัยข้อความสั้นภาษาไทย

dtac – 2-Way SMS

dtac – บริการแจ้งเตือนสายที่ไม่ได้รับ

AIS – บริการโทรกลับนะ
